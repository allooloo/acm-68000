ACM-68000

State determines behavior. Seven states, fixed meanings. The number is the contract.

The reference site is acm-68000.org. The machine form is acm-68000.org/signals.json.

SignalStateAction
ACM-000NOT_APPLICABLENo action required.
ACM-200ALLOWExecute the transaction.
ACM-300CONDITIONALEvaluate before proceeding.
ACM-403RESTRICTHalt transaction.
ACM-404NOT_FOUNDAbort transaction.
ACM-451ESCALATEHuman-in-the-loop required.
ACM-500SYSTEM_ERRORRetry or fallback.
